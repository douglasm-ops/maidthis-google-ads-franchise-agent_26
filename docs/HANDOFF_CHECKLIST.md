# Human launch handoff checklist

## Business

- [ ] Service list matches what the location sells and can fulfill.
- [ ] Service area and exclusions are approved.
- [ ] Hours and lead-response owner are approved.
- [ ] Phone, landing pages, privacy page, offers, guarantees, and proof claims are approved.

## Google Ads

- [ ] Account identity confirmed privately.
- [ ] Campaigns created paused.
- [ ] Search location option is Presence.
- [ ] Search Display Network is off.
- [ ] Search Partners decision is documented.
- [ ] Keywords map to service intent and landing pages.
- [ ] Negative keyword routing is reviewed.
- [ ] Location-specific RSA copy draft is generated and reviewed per enabled service.
- [ ] RSA and P-Max assets are complete and policy-safe.
- [ ] LSA eligibility/verification is complete if used.

## Measurement

- [ ] One canonical form success event.
- [ ] One canonical qualified-call event.
- [ ] CRM receipt verified.
- [ ] No duplicate GTM/tag/event paths.
- [ ] Primary vs secondary conversion settings reviewed.
- [ ] Test click/form/call reconciled.

## Approval

- [ ] Diff reviewed by location owner.
- [ ] Diff approved by authorized operator.
- [ ] Deployment mode remains paused until the approval is recorded.
- [ ] Post-write verification report saved privately.
